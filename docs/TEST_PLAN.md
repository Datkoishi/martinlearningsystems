# Test plan

Ưu tiên P0: rich content schema (valid/invalid/unsafe link/alt), asset references, fixed order/version, shared stimulus/group policy, answer leakage, import idempotency/reference/license, autosave/submit idempotency, scoring types, IDOR/tenant, insufficient evidence.

Mỗi feature cần happy path, edge case và negative authorization nếu có quyền. Gate hiện tại: `npm test --prefix backend`, `npm run build --prefix frontend`; DB migration smoke bằng MySQL 8.4; browser responsive/a11y khi preview tooling khả dụng. 20 acceptance cases từ master prompt giữ ID `AC-01`…`AC-20` trong report khi triển khai.

Import gates bổ sung: ZIP/binary sai, path traversal/symlink/encryption/zip bomb, duplicate path, checksum/size/MIME, unsafe SVG, missing rich asset, missing/extra answer, group/stimulus/exam refs, rights, idempotency và source bytes preserved. HTTP/auth/MySQL integration phải pass trước khi đổi `IMP-001a` sang VERIFIED.

Reviewer gates: preview phải được dựng từ source ZIP, asset/answer đúng; package INVALID không lộ preview; report hash được bind; decision transaction chỉ từ READY_FOR_REVIEW; lần quyết định thứ hai trả 409; status không bao giờ tự chuyển PUBLISHED; Editor nhận 403 ở preview và Reviewer nhận 403 ở upload; creator tự review nhận `SELF_REVIEW_FORBIDDEN`.

Auth gates: password hash không chứa plaintext; credential sai không phân biệt account tồn tại; raw session/CSRF token không lưu DB; revoked/expired session trả 401; cookie/CSRF mismatch trả 403; role guard fail-closed; login throttling trả 429; audit login/import/review; production cookie Secure qua cấu hình.

Publish gates: academic decision chỉ sau technical approval; reject/decision thứ hai bất biến; source SHA và canonical validation report phải khớp; validator chạy lại; asset/option refs chuyển UUID nội bộ; toàn bộ source/license/content/version/reference/publication/audit/status commit hoặc rollback; retry không duplicate; formal assessment luôn bị khóa; Editor/unauth/missing CSRF nhận 403/401.

Catalog/attempt gates: chỉ `PUBLISHED + FIXED + non-formal`; projection không có answer/explanation/scoring hoặc asset explanation-only; published asset phải thuộc student-visible reference và khớp size/hash; Student + CSRF mới tạo attempt; retry cùng key trả cùng ID/hash và chỉ một audit; key dùng cho đề khác trả 409; Student khác nhận 404; snapshot tamper fail-closed; scoring snapshot chỉ tồn tại server-side. MySQL migration và HTTP 401/403/CSRF/IDOR matrix phải pass trước khi `PLAY-001a` thành VERIFIED.

Attempt persistence/scoring gates: autosave type validation; exact retry; key misuse; refresh recovery; stale revision có `details.currentRevision`; local-dirty conflict merge; submit retry/different-key không tạo thêm score hoặc submit audit; autosave sau submit bị chặn; owner/role/CSRF negative cases. Scoring phải test single, multiple exact + opt-in partial penalty, true/false subparts, numeric tolerance, normalized short text, unanswered và answered essay pending. Reveal negative tests phải chứng minh mock/diagnostic/pending không có correct answer/explanation/rubric và PRACTICE chỉ mở answer khi FINAL. MySQL 8.4 migration/upsert/transaction smoke + HTTP route matrix phải pass trước khi `PLAY-001b` thành VERIFIED.

Assembly foundation gates: blueprint schema/quota sum/formal lock/seed; same seed reproducible dù pool order đổi; published FIXED membership; valid derivative license/date; complete indexed metadata; exact topic/skill/type/difficulty quota; point/time/source limits; no duplicate question/family; atomic group không tách; split group luôn có stimulus; insufficient pool/search/assets có structured error; public run không answer/scoring; owner/role/CSRF/IDOR/idempotency/integrity negative cases. MySQL 8.4 migration/query/run/audit smoke phải pass trước khi `ASM-001a` thành VERIFIED.

Assembly governance/delivery gates: BlueprintVersion NEEDS_REVIEW; reviewer preview protected và có answer/lời giải; explanation asset chỉ reviewer-scoped; unselected asset không vào snapshot; creator self-review bị chặn; decision thứ hai bất biến; review bind selection/source snapshot hashes; reject không publish; approve mới publish; retry không tạo ExamVersion/publication/audit mới; published student snapshot không answer; catalog hash tamper fail-closed; public asset chỉ từ student snapshot; Student/Editor/Reviewer/CSRF negative matrix. Attempt ASSEMBLED phải sao chép publication snapshot và reload/retry không gọi lại engine. MySQL 8.4 migration 010 + transaction/catalog/attempt smoke phải pass trước khi `ASM-001b` thành VERIFIED.

Blueprint revision/queue gates: new identity vẫn bắt đầu version 1; revision giữ identity nhưng version/run/snapshot cũ bất biến; chỉ latest `REJECTED|PUBLISHED` được nối version; stale source và latest `NEEDS_REVIEW|APPROVED` trả conflict; concurrent/exact retry không duplicate hoặc trùng version number. Editor queue phải owner-scoped; Reviewer queue loại creator; allowlist status/purpose, query length và page/limit fail-closed. Queue JSON không được chứa student/scoring snapshot, answer key hoặc explanation; preview chỉ tải sau khi chọn item. HTTP role/CSRF/idempotency matrix, frontend build và opt-in MySQL 8.4 transaction/query integration phải pass trước khi `ASM-001c` thành VERIFIED.

Production runtime gates: dev defaults vẫn chạy local; production hợp lệ cần HTTPS origin + Secure cookie + DB secret; malformed boolean/integer/origin và password mẫu phải fail trước listen. Liveness không chạm DB; readiness 503 khi DB lỗi hoặc draining; trusted proxy hop được áp đúng. Image frontend phải `nginx -t` PASS, `/healthz` 200, CSP/security headers hiện diện và upload limit 26 MiB. Backend image thiếu production secret phải exit non-zero; image cấu hình hợp lệ phải live 200/ready 503 khi DB cố ý vắng và kết thúc trong grace khi SIGTERM.

Migration/restore gates: chỉ nhận file `NNN_name.sql` liên tục; status/apply phải phát hiện file mất, sequence/checksum drift; advisory lock timeout chặn migrator song song; fresh apply skip DEMO mặc định và retry no-op; `--include-demo` chỉ có tác dụng ở lần đầu; schema cũ không ledger fail-closed cho đến khi `--adopt-existing`; adoption yêu cầu sentinel prefix đầy đủ và chặn partial/later evidence. MySQL health phải query bằng application user/database, không pass trong temporary init server. Backend image phải chứa đúng SQL/CLI và Compose chỉ mở backend sau migrator thành công. MySQL 8.4 phải pass fresh/adopt/inconsistent/demo/lock/entrypoint-compat smoke. Dump single-transaction phải có checksum, restore vào database riêng, khớp table/column/ledger/data invariant và runner status.

Scheduled backup gates: config/path/boolean/integer fail-closed; dump + import archive + manifest/ledger/invariants có SHA-256 và chỉ xuất hiện `READY/latest` sau verify; byte tamper bị chặn; concurrent job không chạy và không xóa lock của owner; stale lock chỉ dọn sau timeout; retention chỉ xóa complete expired set, không xóa current/partial. Health phải fail khi thiếu/quá hạn hoặc failure mới hơn success và phục hồi sau verified success. Restore checker chỉ nhận `eduassess_restore_*` + exact confirmation, restore trên MySQL cô lập, so ledger/schema invariants, ghi success marker và drop target ở cả success/failure. Compose source volume read-only, root filesystem read-only; artifact/manifest không có credential. Production deployment phải test encrypted/off-site destination và alert delivery riêng.

Object storage gates: disabled mặc định và malformed endpoint/bucket/prefix/credential pair fail-fast; production custom endpoint HTTP bị chặn. Promotion chỉ nhận PUBLISHED archive asset, xác minh archive hash/size, tạo exact content-address key, conditional PUT + GET verification trước DB cutover; existing correct object được reuse, collision/corrupt upload không đổi DB. Active object read phải khớp key/hash/size; runtime ưu tiên object và chỉ fallback archive khi flag cho phép. Retry không thêm event/audit; rollback verify archive dưới metadata lock, ghi transition/audit, giữ object và chặn automatic re-promotion. CLI flag vô nghĩa/không hợp lệ phải exit non-zero JSON. MySQL 8.4 migration 012 + S3-compatible API smoke, Node 24 container builds/tests, Compose config và production dependency audit phải pass trước khi OPS-001d thành VERIFIED.

Production TLS/secrets/observability gates: direct secret và `_FILE` phải loại trừ nhau; relative/missing/empty/multiline file bị chặn; production metrics cần token >=32 ký tự và port riêng. HTTP metric label phải dùng route template/unmatched, không chứa UUID; metrics listener không token trả 401, token đúng trả 200. Object reads phải ghi đủ object/fallback/failure; backup textfile phải atomic, healthy→unhealthy đúng failure ordering và secret file không bị export từ loop dài hạn. Compose merge phải xóa MySQL/backend host port + plaintext DB password, chỉ edge publish 80/443; Nginx config/TLS redirect/HSTS/API proxy pass. `promtool` phải validate config + 8 rules, `amtool` validate receiver. Full production fixture stack phải đạt MySQL/backend/frontend/backup healthy, migrate exit 0, protected scrape 401/200, Prometheus backend up + backup healthy và Alertmanager ready. Certificate/domain thật, encrypted off-site destination và webhook delivery drill là target gate riêng, không được suy ra từ fixture smoke.
