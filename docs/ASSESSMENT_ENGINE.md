# Assessment Engine

Chưa triển khai. Scoring và đánh giá năng lực là hai boundary riêng. Assessment cần framework/rubric/evidence/interpretation rule có version và approval. Nếu coverage/min evidence/task type chưa đủ, kết quả là `Chưa đủ bằng chứng`. Không hardcode ngưỡng phần trăm thành mức năng lực. Formal assessment mặc định disabled cho đến khi có validation và approver/audit.
