# Roadmap

1. **Phase 0/1a — hoàn thành kỹ thuật:** audit, docs baseline, rich-content/data foundation, student-safe FIXED DEMO.
2. **Phase 1b — đang làm:** ZIP staging, validation, session/RBAC và technical reviewer decision đã có; tiếp theo là academic approval, S3 adapter và atomic publish transaction.
3. **Phase 2:** tenant-scoped access, attempt snapshot, autosave idempotent, submit/scoring/reveal policy.
4. **Phase 3:** question bank và deterministic ASSEMBLED engine.
5. **Phase 4:** evidence framework, recommendations và cấu hình pilot lớp 5/9/12 có approval.
6. **Phase 5+:** teacher/guardian/school scope, manual essay, operations hardening; sau đó Word/PDF nâng cao.

Task kế tiếp cụ thể: `IMP-001c` — mô hình academic approval tách biệt và atomic publish transaction, giữ `TECHNICALLY_APPROVED` không thể tự chuyển thành nội dung live.
